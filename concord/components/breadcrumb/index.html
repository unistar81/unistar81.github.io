Breadcrumb

A native breadcrumb navigation trail that composes Link for navigable ancestors and identifies the current page without making it an unnecessary self-link.

WCAG 2.2 AA target

Accessibility notes
  • The nav landmark is named with aria-label="Breadcrumb".
  • The ordered list communicates the hierarchical sequence.
  • The final item is non-interactive and identified with aria-current="page".
  • Visual separators are generated by CSS and are not authored as breadcrumb content.

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Canonical HTML uses a native nav landmark containing an ordered list of breadcrumb locations.
  • Navigable ancestors compose the existing Link component and therefore retain native anchor semantics and interaction.
  • The final current page is non-interactive and identified with aria-current="page".
  • Separators are CSS-generated presentation and are not authored as breadcrumb content.

Requirements

  • Provide an accessible name for the breadcrumb nav, normally aria-label="Breadcrumb".
  • Use distinct accessible names when more than one breadcrumb landmark appears on the same page and needs disambiguation.
  • Keep ancestor labels concise and destination-specific.
  • Do not add redundant visually hidden breadcrumb-identification text when the nav accessible name already supplies that context.
  • Do not use the Divider component as breadcrumb punctuation.
