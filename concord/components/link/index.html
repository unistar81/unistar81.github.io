Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses a native anchor with an href for navigation.
  • Retains native keyboard focus, Enter-key activation, context menus, and destination discovery.

Requirements

  • Use meaningful visible text that describes the destination.
  • Keep decorative icons hidden from the accessibility tree with aria-hidden="true".
  • Use target="_blank" only when opening a new browsing context is intentional.
  • Do not use Link for actions that should be implemented with a native button.

Keyboard

Enter
Activates the focused native anchor.
