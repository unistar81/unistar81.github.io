/* === CONCORD BUTTON LABEL CONTRACT: START === */
/*
 * Every labeled Button exposes one stable direct-child .label wrapper.
 * The Button root still owns control geometry and supplies typography values
 * for icon-only/em-based sizing. The label wrapper owns visible label typography so
 * consumer/documentation typography cannot silently replace the Button label.
 */
.dsl-button > .label {
  display: inline-block;
  min-inline-size: 0;
  color: inherit;
  font-family: var(--dsl-component-button-typography-family);
  font-size: var(--_dsl-button-font-size);
  font-weight: var(--dsl-component-button-typography-weight);
  line-height: var(--dsl-component-button-typography-line-height);
  white-space: inherit;
  overflow-wrap: inherit;
}
/* === CONCORD BUTTON LABEL CONTRACT: END === */

/* === CONCORD BUTTON ICON FOREGROUND CONTRACT: START === */
/*
 * A Button owns the foreground contract of monochrome icons placed inside it.
 * This prevents a nested icon token/opacity from weakening contrast on filled
 * primary/secondary/circular controls.
 */
.dsl-button:not(:disabled) .dsl-icon,
.dsl-button:not(:disabled) .dsl-icon::before {
  color: currentColor;
  opacity: 1;
}

.dsl-button:not(:disabled) .dsl-icon {
  --dsl-icon-color: currentColor;
}

.dsl-button:not(:disabled) .dsl-icon svg {
  color: currentColor;
}

.dsl-button:not(:disabled) .dsl-icon svg [fill]:not([fill='none']) {
  fill: currentColor;
}

.dsl-button:not(:disabled) .dsl-icon svg [stroke] {
  stroke: currentColor;
}
/* === CONCORD BUTTON ICON FOREGROUND CONTRACT: END === */

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses the native button element.
  • Retains native keyboard activation, form behavior, and disabled semantics.

Requirements

  • Every button must have an accessible name.
  • Text-button variants should use their visible text as the accessible name.
  • Icon-only buttons must provide an explicit accessible name such as aria-label.
  • Decorative icons must use aria-hidden="true".
  • The type attribute must be declared to prevent accidental form submission.
  • Do not add tabindex="0" because native buttons are already keyboard focusable.

Keyboard

Enter / Space
Activates the enabled native button.
