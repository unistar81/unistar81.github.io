List Item

A compact, container-driven row shell with optional leading and trailing regions around required flexible content. List Item owns one row; parent lists, stacks, and grids own relationships among rows.

WCAG 2.2 AA target

Example 01

—

Anatomy

One canonical member row shows the three-region model clearly: Leading is optional, Content is required, and Trailing is optional. Supporting and Meta belong to the Content hierarchy rather than becoming separate List Item variants.

Key configuration
Leading · optionalContent · requiredTrailing · optionalLabel / Supporting / Meta

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses native ul or ol and li semantics when the content is genuinely a list.
  • Uses a native anchor when the complete row navigates and a native button when the complete row performs an action.
  • Keeps a row structurally noninteractive when it contains an independent Toggle or other trailing control.

Requirements

  • Do not add click behavior to a generic div.
  • Do not nest interactive controls inside an anchor or button row wrapper.
  • Every interactive row and trailing control must have a meaningful accessible name.
  • Decorative icons must use aria-hidden="true".
  • Meaningful images require useful alternative text; decorative avatar and media images use empty alternative text.
  • Heading elements inside a row must preserve the surrounding document hierarchy.
  • Do not truncate content by default or convey meaning only through color or position.

Keyboard

Enter
Activates a focused native anchor or button row.
Space
Activates a focused native button row or trailing native control.
