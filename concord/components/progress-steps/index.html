Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses an ordered list because sequence and position are meaningful.
  • Uses native list items for each process step.
  • Uses aria-current="step" to identify the current step.
  • Remains noninteractive unless a separate documented navigation variant is introduced.

Requirements

  • The root list must have an accessible name describing the represented process.
  • Only one step may use aria-current="step" at a time.
  • Completed state must not be communicated by color or a decorative checkmark alone.
  • Completed steps should include visually hidden completion text or another equivalent textual status.
  • The data-completed attribute is only a styling hook and does not provide semantic completion information.
  • Markers and generated checkmarks must be hidden from assistive technology.
  • Do not add buttons or links unless the product permits step navigation and the interaction contract is documented separately.
  • The compact responsive presentation must preserve public custom-property overrides.
  • Forced-colors mode must preserve distinguishable completed, current, and upcoming states.
