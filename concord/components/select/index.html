Select

A native select that preserves platform selection behavior, option grouping, form semantics, and token-driven states.

WCAG 2.2 AA target

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Preserves native select, option, and optgroup semantics together with browser keyboard and form behavior.
  • Uses a disabled empty-value option as placeholder-style content when a prompt is needed; this does not replace the Select accessible name.
  • Form Label, supporting/help text, and validation-message markup are external field composition rather than Select anatomy.

Requirements

  • Every select requires an accessible name supplied by a visible external label, aria-labelledby, or aria-label.
  • Keep option and optgroup semantics native rather than replacing them with generic interactive elements when native select behavior satisfies the requirement.
  • Use the native disabled attribute to prevent interaction rather than a styling-only state.
  • Set aria-invalid when the selected value is known to be invalid.
  • When external guidance or validation messaging applies, associate it with the native select using aria-describedby.
  • Do not use placeholder option text as the only accessible name for the select.
