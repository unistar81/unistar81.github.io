Accordion

A disclosure group that reveals related sections independently or enforces one open section at a time.

WCAG 2.2 AA target

Example 01

—

Heading and supporting text

The trigger can pair its primary heading with a concise supporting description.
Preview width
Auto

Your name, primary contact information, preferred language, and communication details are managed here. Keep these details current so account notices and recovery messages reach the correct destination. Some organization-managed fields may be visible without being editable.

Review billing contacts, saved payment methods, invoice history, and the payment profile used for recurring charges. Workspace owners can also confirm which billing details are inherited from the organization account.

Control product updates, required account notices, release announcements, and optional newsletters. Essential security and service communications remain enabled when they are required to operate the account safely.

Exclusive group

Opening one item closes the previously open item when the group uses exclusive behavior.

Key configuration
data-exclusive
Preview width
Auto

Manage the name, contact details, locale, and profile information shared across your Concord workspace. Changes are reflected anywhere this account is used as the source of personal information.

Choose which product updates, workspace activity messages, and optional announcements you want to receive. Required security and account-administration notices are identified separately from optional communication.

Control profile visibility, approved data sharing, and personalization settings for this account. Organization policy can establish minimum privacy requirements while still allowing individual preferences where appropriate.

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • The custom Accordion host is a composite boundary; native button triggers and labelled regions retain disclosure semantics.
  • Uses native buttons for every disclosure trigger.
  • Connects each trigger and panel through aria-controls and aria-labelledby.
  • Uses role=region for labelled disclosure content.

Requirements

  • Every trigger must have a stable accessible name and unique ID.
  • Every aria-controls value must reference the matching panel ID.
  • Collapsed panels must use the hidden attribute.
  • The indicator is decorative and must use aria-hidden=true.
  • Use exclusive behavior only when users do not need to compare multiple panels.

Keyboard

Enter / Space
Toggles the focused disclosure using native button behavior.
