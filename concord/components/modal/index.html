A focused task surface built on the native dialog element, modal top layer, and browser-provided focus containment.

Accessibility notes
  • showModal() places the native dialog in the top layer and makes the surrounding document inert.
  • The visible heading labels the dialog through aria-labelledby; the concise supporting text is referenced by aria-describedby.
  • Submitting the method="dialog" action form closes natively and sets dialog.returnValue.
  • Cancel receives native autofocus as the conservative initial action for this confirmation task.
  • Closing the modal returns focus to its invoking control through native dialog behavior.

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses the native dialog element and showModal() for top-layer modal behavior.
  • Relies on the browser to make surrounding document content inert while the modal is open.
  • Uses a visible heading referenced by aria-labelledby.
  • Keeps long task content in an internal scroll region while the heading, close control, and actions remain reachable.

Requirements

  • Open modal dialogs with showModal() or the native show-modal command; do not use the open attribute as a substitute for modal behavior.
  • Provide a visible programmatically associated heading.
  • Provide an explicit close or cancel path in addition to native Escape behavior.
  • Choose initial focus intentionally when a task has a clear first control; otherwise preserve native dialog focus behavior.
  • Do not add a second JavaScript focus trap or aria-modal when native showModal() already supplies modal semantics and inertness.
  • Use method=dialog or close()/requestClose() when an action should dismiss the modal.
  • Keep the complete modal surface inside the dynamic viewport and contain scroll chaining from long content.

Keyboard

Tab / Shift+Tab
Moves through focusable controls inside the native modal dialog while the surrounding document remains inert.
Escape
Requests native dialog cancellation and closes the modal unless the cancel event is prevented.
