Loading Indicator

An indeterminate loading status with optional visible label and supporting description.

WCAG 2.2 AA target

Example 01

—

Indicator only

The visual indicator can appear without visible text when an accessible status label is provided.
Preview width
Auto
packages/html/src/components/loading-indicator/loading-indicator.html 
<div class="dsl-loading-indicator" role="status" aria-label="Loading">
  <span class="indicator" aria-hidden="true"></span>
</div>
packages/components-lit/src/loading-indicator/dsl-loading-indicator.ts 
<dsl-loading-indicator
  accessible-label="Loading"
></dsl-loading-indicator>
packages/react/src/examples/index.tsx 
<LoadingIndicator
  accessibleLabel="Loading"
/>
Accessibility notes
  • The animated indicator is decorative and hidden from the accessibility tree.
  • When no visible label is present, provide an accessible status label.

Component implementation

packages/css/src/components/loading-indicator.css 
.dsl-loading-indicator {
  display: inline-block;
  max-inline-size: var(--dsl-loading-indicator-width, 100%);
  color: var(--dsl-component-loading-indicator-content-color);
  text-align: center;

  > .indicator {
    position: relative;
    display: inline-block;
    inline-size: var(--dsl-component-loading-indicator-size);
    block-size: var(--dsl-component-loading-indicator-size);
  }

  > .indicator::before {
    content: '';
    position: absolute;
    inset: 0;
    box-sizing: border-box;
    border: var(--dsl-component-loading-indicator-track-width) solid
      var(--dsl-component-loading-indicator-track-color);
    border-block-start-color: var(--dsl-component-loading-indicator-active-color);
    border-inline-end-color: var(--dsl-component-loading-indicator-active-color);
    border-block-end-color: var(--dsl-component-loading-indicator-active-color);
    border-radius: 50%;
    animation: dsl-loading-indicator
      var(--dsl-component-loading-indicator-motion-duration) linear infinite;
  }

  > .label,
  > .description {
    display: block;
    margin-block-start: var(--dsl-component-loading-indicator-spacing-gap);
    overflow-wrap: anywhere;
  }

  > .label {
    font-size: var(--dsl-component-loading-indicator-label-typography-size);
    line-height: var(--dsl-component-loading-indicator-label-typography-line-height);
  }

  > .description {
    color: var(--dsl-component-loading-indicator-description-color);
    font-size: var(--dsl-component-loading-indicator-description-typography-size);
    line-height: var(
      --dsl-component-loading-indicator-description-typography-line-height
    );
  }
}

@keyframes dsl-loading-indicator {
  to {
    transform: rotate(1turn);
  }
}

@media (prefers-reduced-motion: reduce) {
  .dsl-loading-indicator > .indicator::before {
    animation: none;
    transform: rotate(45deg);
  }
}

@media (forced-colors: active) {
  .dsl-loading-indicator > .indicator::before {
    border-color: GrayText;
    border-block-start-color: Highlight;
    border-inline-end-color: Highlight;
    border-block-end-color: Highlight;
  }
}
