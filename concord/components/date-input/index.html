Date Input

A native date input that delegates locale display and picker behavior to the browser.

WCAG 2.2 AA target

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses a native input type="date" so picker behavior, keyboard interaction, locale presentation, constraint validation, and form participation remain browser-owned.
  • Uses the shared Input wrapper only for visual presentation.
  • Form Label, supporting/help text, and validation-message markup are external field composition rather than Date Input anatomy.

Requirements

  • Every date input requires an accessible name supplied by a visible external label, aria-labelledby, or aria-label.
  • Do not replace the native date input with a scripted text field when native date semantics satisfy the requirement.
  • Use min and max on the native date input when the accepted interval is constrained.
  • Set aria-invalid when an entered or selected value is known to be invalid.
  • Use the native disabled attribute to prevent interaction rather than a styling-only state.
  • When external date guidance or validation messaging applies, associate it with the native input using aria-describedby.
  • Do not assume the visible date format; browser and locale presentation may differ while the machine value remains YYYY-MM-DD.
