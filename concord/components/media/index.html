Media

A presentation-only frame for native img, picture, and video children. Ratio-controlled Media frames normalize arbitrary source geometry using centered cropping without distortion or empty space, while declarative radius presets handle intentional frame rounding. Choose Retain to preserve the source’s intrinsic aspect ratio.

WCAG 2.2 AA target

WCAG 2.2 AA target

Native semantics

  • Preserves native img, picture, source, video, and track semantics without adding a component role.
  • Keeps native video controls and keyboard behavior on the video element.

Requirements

  • Provide useful alt text for meaningful images and alt="" for decorative images.
  • Place alternative text on the img inside picture; source elements do not use alt.
  • Provide video controls and captions or transcripts for meaningful prerecorded media.
  • Avoid autoplay, preserve a useful poster when supplied, and honor reduced-motion preferences.
  • Do not use a visual caption as a replacement for required image alternative text or video captions.

Keyboard

Native media controls
Uses the browser and platform keyboard behavior exposed by the video controls.
