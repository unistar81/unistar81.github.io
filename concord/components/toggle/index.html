Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • The custom Toggle host is a presentation boundary; the native checkbox remains the form control and owns checked, disabled, focus, and keyboard behavior.
  • Uses a native checkbox input for form, keyboard, focus, checked, and disabled behavior.
  • Uses role="switch" to expose the binary state as on or off.
  • Uses a native wrapping label so the complete component is an activation target.

Requirements

  • Every toggle must have a stable accessible name.
  • The visible label should describe the setting and should not change between the off and on states.
  • The native checked property supplies the switch state; do not add a separate manually synchronized aria-checked value.
  • The decorative slider must use aria-hidden="true".
  • Use a switch for an immediate binary setting rather than for selecting multiple independent form options.
  • Reduced-motion preferences must suppress the ordinary track and thumb transition duration.
  • Forced-colors mode must retain visible track, thumb, focus, checked, and disabled states.
  • Do not add tabindex="0" because the native checkbox input is already keyboard focusable.
