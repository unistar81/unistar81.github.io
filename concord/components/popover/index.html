Popover

A non-modal contextual surface built on the native Popover API and anchored to its invoking control.

WCAG 2.2 AA target

Example 01

—

Anchored contextual popover

A Concord button opens a non-modal surface below and centered on its invoker by default, flipping to the opposite side when the preferred side cannot fit.

Accessibility notes
  • The visible heading labels the non-modal dialog with aria-labelledby.
  • The close control has an explicit accessible name.
  • popovertarget supplies the native invoker relationship and the anchor used by modern CSS positioning.

/*
 * popovertarget creates the implicit anchor relationship. The default
 * placement follows the common contextual-popover model:
 *
 *   side:  bottom
 *   align: center
 *
 * The browser flips to the opposite side when the preferred side cannot fit.
 * side and align remain independent configuration axes rather than twelve
 * named variants.
 */
@supports (position-area: block-end center) {
  /*
   * Center alignment uses position-area, which gives the center axis a native
   * anchor-center alignment container. This is the stable canonical path for
   * the default contextual Popover.
   */
  @position-try --dsl-popover-shrink-left {
    position-area: inline-start center;
    max-inline-size: calc(100% - var(--_dsl-popover-anchor-gap));
    margin-inline-end: var(--_dsl-popover-anchor-gap);
  }

  @position-try --dsl-popover-shrink-right {
    position-area: inline-end center;
    max-inline-size: calc(100% - var(--_dsl-popover-anchor-gap));
    margin-inline-start: var(--_dsl-popover-anchor-gap);
  }

  .dsl-popover[popover] {
    inset: auto;
    margin: var(--_dsl-popover-anchor-gap) 0 0;
    position-area: block-end center;
    block-size: max-content;
    max-block-size: min(
      var(--dsl-component-popover-size-max-height),
      calc(100% - var(--_dsl-popover-anchor-gap) - var(--_dsl-popover-viewport-gap))
    );
    position-try-fallbacks: flip-block;
  }

  .dsl-popover[popover][data-side='top'] {
    margin: 0 0 var(--_dsl-popover-anchor-gap);
    position-area: block-start center;
    block-size: max-content;
    max-block-size: min(
      var(--dsl-component-popover-size-max-height),
      calc(100% - var(--_dsl-popover-anchor-gap) - var(--_dsl-popover-viewport-gap))
    );
    position-try-fallbacks: flip-block;
  }

  .dsl-popover[popover][data-side='bottom'] {
    margin: var(--_dsl-popover-anchor-gap) 0 0;
    position-area: block-end center;
    block-size: max-content;
    max-block-size: min(
      var(--dsl-component-popover-size-max-height),
      calc(100% - var(--_dsl-popover-anchor-gap) - var(--_dsl-popover-viewport-gap))
    );
    position-try-fallbacks: flip-block;
  }

  .dsl-popover[popover][data-side='left'] {
    margin: 0;
    margin-inline-end: var(--_dsl-popover-anchor-gap);
    position-area: inline-start center;
    position-try-fallbacks: flip-inline, --dsl-popover-shrink-left;
  }

  .dsl-popover[popover][data-side='right'] {
    margin: 0;
    margin-inline-start: var(--_dsl-popover-anchor-gap);
    position-area: inline-end center;
    position-try-fallbacks: flip-inline, --dsl-popover-shrink-right;
  }

  /*
   * A spanning position area plus start/end alignment follows the invoker's
   * exact edge. Use the same implicit-anchor path as center: some engines do
   * not resolve an implicit invoker inside anchor() inset functions.
   */
  .dsl-popover[popover]:is(:not([data-side]), [data-side='bottom'])[data-align='start'] {
    position-area: block-end span-inline-end;
    justify-self: start;
    position-try-fallbacks:
      flip-block,
      flip-inline,
      flip-block flip-inline;
  }

  .dsl-popover[popover]:is(:not([data-side]), [data-side='bottom'])[data-align='end'] {
    position-area: block-end span-inline-start;
    justify-self: end;
    position-try-fallbacks:
      flip-block,
      flip-inline,
      flip-block flip-inline;
  }

  .dsl-popover[popover][data-side='top'][data-align='start'] {
    position-area: block-start span-inline-end;
    justify-self: start;
    position-try-fallbacks:
      flip-block,

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses the native popover attribute and popovertarget invoker relationship.
  • Uses a labelled non-modal dialog surface for richer contextual content.
  • Keeps interactive controls in normal document focus order without modal focus containment.

Requirements

  • Provide a visible heading and reference it with aria-labelledby.
  • Provide an explicitly named close control when the design includes one.
  • Do not trap focus in a non-modal popover.
  • Use Tooltip instead when the content is only a short noninteractive description.
  • Preserve native light dismiss and Escape behavior for auto popovers.

Keyboard

Tab / Shift+Tab
Moves through reachable controls in normal document order.
Escape
Uses native auto-popover behavior to dismiss the topmost open popover.
