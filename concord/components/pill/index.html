Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses a native checkbox for independently selectable filter or preference options.
  • Uses a native wrapping label so the complete visible pill is clickable.
  • Keeps the native input focusable while visually hiding its browser presentation.

Requirements

  • Every selectable pill must have an accessible name.
  • The visible label normally supplies the accessible name through the wrapping native label.
  • The generated selected checkmark is decorative and must not create duplicate accessible content.
  • Use checkboxes when multiple pills may be selected independently.
  • Use radio semantics instead when exactly one option in a group may be selected.
  • Use a button instead when activation performs an immediate action rather than changing a selected value.
  • Forced-colors mode must retain visible selected, disabled, and focus states.
  • Do not remove the native input from the accessibility tree with display:none, visibility:hidden, or aria-hidden.

Keyboard

Space
Toggles the enabled pill between unselected and selected.
