Tooltip

Short supplemental text revealed from an already-named trigger on pointer hover or keyboard focus.

WCAG 2.2 AA target

An information button keeps its own accessible name while the tooltip supplies a short supporting description.

Accessibility notes
  • The icon-only button has its own accessible name and references the tooltip with aria-describedby.
  • The tooltip supplements the trigger name; it never becomes the trigger’s only accessible label.
  • Enhanced tooltips dismiss with Escape without moving focus away from the trigger.
  • Tooltip content remains hoverable while visible but must remain noninteractive.

packages/css/src/components/tooltip.css 
.dsl-tooltip-anchor {
  position: relative;
  display: inline-block;
  inline-size: fit-content;
  max-inline-size: 100%;
  vertical-align: top;

  > .dsl-tooltip {
    position: absolute;
    z-index: var(--dsl-tooltip-z-index, 1);
  }

  > .dsl-tooltip[data-position='top'] {
    inset-block-end: calc(100% + var(--dsl-component-tooltip-spacing-offset));
    inset-inline-start: 50%;
    transform: translateX(-50%);
  }

  > .dsl-tooltip[data-position='bottom'] {
    inset-block-start: calc(100% + var(--dsl-component-tooltip-spacing-offset));
    inset-inline-start: 50%;
    transform: translateX(-50%);
  }
}

.dsl-tooltip {
  display: none;
  inline-size: max-content;
  max-inline-size: min(var(--dsl-component-tooltip-size-max-width), calc(100vw - 2rem));
  padding: var(--dsl-component-tooltip-spacing-padding);
  border: var(--dsl-component-tooltip-border-width) solid
    var(--dsl-component-tooltip-border-color);
  border-radius: var(--dsl-component-tooltip-border-radius);
  background: var(--dsl-component-tooltip-surface-background);
  box-shadow: var(--dsl-component-tooltip-shadow);
  color: var(--dsl-component-tooltip-content-color);
  font-size: var(--dsl-component-tooltip-typography-size);
  line-height: var(--dsl-component-tooltip-typography-line-height);
  overflow-wrap: anywhere;

  /*
   * Transparent bridge across the visual offset keeps the tooltip hoverable
   * while the pointer moves between the trigger and the tooltip surface.
   */
  &::before {
    content: '';
    position: absolute;
    inset-inline: 0;
    block-size: var(--dsl-component-tooltip-spacing-offset);
  }

  &[data-position='top']::before {
    inset-block-start: 100%;
  }

  &[data-position='bottom']::before {
    inset-block-end: 100%;
  }

  &::after {
    content: '';
    position: absolute;
    inline-size: var(--dsl-component-tooltip-caret-size);
    block-size: var(--dsl-component-tooltip-caret-size);
    border: inherit;
    background: inherit;
    transform: rotate(45deg);
  }

  &[data-position='top']::after {
    inset-block-end: calc(var(--dsl-component-tooltip-caret-size) / -2);
    inset-inline-start: calc(50% - var(--dsl-component-tooltip-caret-size) / 2);
    border-block-start: 0;
    border-inline-start: 0;
  }

  &[data-position='bottom']::after {
    inset-block-start: calc(var(--dsl-component-tooltip-caret-size) / -2);
    inset-inline-start: calc(50% - var(--dsl-component-tooltip-caret-size) / 2);
    border-block-end: 0;
    border-inline-end: 0;
  }
}

/* Enhanced HTML and Lit use data-visible as the single visibility state. */
.dsl-tooltip-anchor[data-enhanced][data-visible] > .dsl-tooltip {
  display: inline-block;
}

/*
 * HTML/CSS remains useful before JavaScript enhancement. Once enhanced,
 * these selectors intentionally stand down so Escape can dismiss a focused
 * tooltip without moving focus away from its trigger.
 */
.dsl-tooltip-anchor:not([data-enhanced]) > :first-child:hover ~ .dsl-tooltip,
.dsl-tooltip-anchor:not([data-enhanced]) > :first-child:focus-visible ~ .dsl-tooltip,
.dsl-tooltip-anchor:not([data-enhanced]) > .dsl-tooltip:hover {
  display: inline-block;
}

Component contract

Accessibility

WCAG 2.2 AA target

Native semantics

  • Uses an already-named native control as the trigger.
  • Relates supplemental text with aria-describedby and role=tooltip.
  • Keeps focus on the trigger; the tooltip itself is not focusable or interactive.

Requirements

  • Tooltip text must supplement, not replace, the trigger accessible name.
  • Reveal the tooltip for pointer hover and keyboard focus.
  • Allow Escape to dismiss an enhanced tooltip without moving focus.
  • Keep hover-triggered tooltip content hoverable while it remains visible.
  • Do not place interactive controls inside a tooltip; use Popover for interactive content.

Keyboard

Escape
Dismisses the enhanced tooltip while focus remains on its trigger.
