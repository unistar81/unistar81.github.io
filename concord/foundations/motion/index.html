Foundations / Motion

Motion

Motion should clarify state change without becoming a requirement for understanding the interface. Concord keeps duration and easing in shared contracts, assigns those contracts to interaction purpose, and provides a reduced-motion path so meaning survives even when animation is removed.

Visual foundation

Time as a controlled design decision

Motion becomes predictable when duration, easing, interaction purpose, and reduced motion are separate contracts rather than one-off animation values.

Timing belongs to the system

A duration is not useful because it happens to feel fast or slow in one component. Shared timing gives related interactions a consistent rhythm and prevents individual components from accumulating arbitrary transition values.

Foundation motion provides the reusable vocabulary. System motion promotes selected values into stable timing contracts that components can consume without depending on raw duration names.

Easing changes the character of movement

Duration answers how long a transition lasts; easing describes how that time is distributed. Concord's standard curve accelerates and settles intentionally rather than moving at a constant linear rate.

The easing contract can therefore remain stable even when a future theme or system decision changes the exact curve used to express that interaction.

Reduced motion preserves the state change

Reduced motion is not a separate interaction model. The same state transition still happens; only the temporal expression changes. Concord's semantic reduced-duration contract currently resolves through the immediate path, making the state available without requiring animated travel.

Animation must never be the only evidence that something changed. Status, visibility, focus, layout, or other durable interface state still carries the meaning.

Motion is progressive enhancement

Motion should support orientation and feedback when it helps, but the component remains understandable when animation is absent. This is particularly important for loading indicators and other animated treatments whose accessible meaning is carried by status text rather than by the moving graphic itself.
