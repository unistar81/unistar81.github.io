Foundations / Elevation

Elevation

Elevation communicates visual layering without changing document structure. Concord defines reusable shadow foundations, promotes them into stable system contracts, and assigns semantic roles such as raised surfaces and overlays so components can express depth without choosing arbitrary shadow values.

Visual foundation

Depth without changing structure

Concord treats shadows as reusable visual vocabulary, then assigns depth through stable system and semantic contracts rather than arbitrary component decoration.

Shadow anatomy

Offset, blur, spread, and opacity solve different problems

Shadow strength is not one number. The High token below is decomposed so the visual effect can be understood as a set of coordinated decisions.

Surface Y offset 8px Blur 24px Spread −2px Color 16% black
Vertical offset
Moves the shadow away from the source surface.
Blur
Controls softness and how broadly the shadow diffuses.
Spread
Expands or contracts the shadow before blur is applied.
Opacity
Controls visual weight without changing shadow geometry.

Depth is a relationship

A shadow is not useful because it is visually dramatic. It is useful when it helps distinguish one surface from another: a raised region from its page, or an overlay from the content beneath it.

Concord keeps the raw shadow vocabulary separate from the semantic reason for using it. That allows shadow character to evolve while the meaning of “raised” or “overlay” remains stable.

Semantic elevation preserves intent

Foundation shadows describe available visual treatments. System shadow contracts provide a themeable boundary, and semantic elevation assigns purpose. Components such as popovers and modals can therefore consume `semantic.elevation.overlay` without knowing which raw shadow currently represents overlay depth.

A holistic theme can change the softness, offset, blur, spread, or opacity of system shadows while preserving those semantic relationships.

Shadows support boundaries; they do not replace them

Elevation should reinforce layering rather than become the only signal that two surfaces are separate. Borders, surface contrast, backdrop treatment, and document structure may still be necessary when shadows are subtle, unavailable, or reduced by the viewing environment.

Dark appearance, high-contrast modes, and low-contrast displays are useful tests because a shadow that works on one surface may become nearly invisible on another.
