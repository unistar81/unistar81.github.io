Built in agreement

The product changes.
The contract holds.

Concord is web-platform-native and framework-agnostic by architecture.

One contract across delivery
Semantic HTML and CSS define the interface. Native behavior enhances it where needed. Lit and React adapters consume Concord rather than redefine it.
Expression has clear owners
Theme owns visual language. Appearance handles light and dark. Density changes space, not typography or shape.
Composition keeps its source
Patterns and Templates select canonical components. Page arrangement changes without creating another implementation.
