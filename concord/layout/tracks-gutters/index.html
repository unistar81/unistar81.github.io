Tracks & Gutters

Tracks are the row and column regions between Grid lines. CSS gap creates gutters: the empty space between adjacent tracks. Concord keeps both relationships on the owning layout so children do not manufacture alignment or spacing with paired margins.

Layout contract

Tracks form layout regions; gutters separate them

The Grid owns both relationships: tracks form repeated layout regions, while CSS gap creates the empty gutters between them without child margins or device classes.

Tracks are layout geometry

A Grid track is the space between two adjacent Grid lines. Column tracks divide the inline axis; row tracks divide the block axis. A track may be intrinsic, flexible such as 1fr, fixed by an owning composition, or inherited through subgrid.

Track count and track sizing describe geometry. They do not define what the content means, and a track is not a component or content category.

Gutters are layout space, not child margins

CSS Grid creates inter-track spacing with gap, column-gap, and row-gap. This page calls that resulting empty space a gutter. The owning Grid or composition creates it once; children should not recreate the same separation with paired margins.

A gutter consumes layout space between tracks but contains no item content. Changing a gutter can therefore change the room remaining for tracks without changing item semantics.

Column and row gaps are separate axes

Column gap controls separation between adjacent column tracks. Row gap controls separation between adjacent row tracks. Concord's base Grid lets those axes share one rhythm by default while still allowing the owning composition to separate them when the relationship genuinely requires it.

Grid gap properties

The public Grid API exposes one property per axis. Keep these values on the Grid or composition that owns the spacing relationship.

Column gutter --dsl-grid-column-gap
Separation between adjacent column tracks. Default · semantic layout content gap · 16px fallback
Row gutter --dsl-grid-row-gap
Separation between adjacent row tracks. Default · follows the resolved column gutter

Grid gutters are not page gutters

The word gutter appears at two different layout levels and should not blur their ownership.

Content Boundary uses --dsl-container-gutter for the space between the page edge and the bounded content area. Grid uses --dsl-grid-column-gap and --dsl-grid-row-gap for separation between adjacent tracks inside a composition.

Page-edge gutters belong to the boundary. Inter-track gutters belong to the Grid.

Responsive adjustment follows ownership

Do not automatically reduce every Grid gap because a viewport crossed a generic device threshold. If a composition genuinely needs a different gutter when its own local space changes, that composition owns the responsive condition and the gap override.

Otherwise, keep the semantic Grid gap stable and let track sizing, wrapping, and available space do the responsive work.
